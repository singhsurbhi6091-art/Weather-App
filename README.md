# 🌦️ Weather App

A responsive Weather App built using **React.js and Vite** that allows users to check weather information for different cities.

## ✨ Features

- 🌍 Search weather by city name
- 🌡️ Display current temperature
- 💧 Show humidity
- 🌬️ Display wind speed
- ☁️ Show weather conditions
- 📱 Responsive user interface
- ⚡ Fast performance with Vite

## 🛠️ Tech Stack

- **Frontend:** React.js
- **Build Tool:** Vite
- **Styling:** CSS
- **API:** Weather API
- **Programming Language:** JavaScript

## 🚀 Getting Started

Follow these steps to run the project locally.

### 1. Clone the Repository

```bash
git clone https://github.com/singhsurbhi6091-art/Weather-App.git
```

### 2. Navigate to the Project Directory

```bash
cd weather-app
```

### 3. Install Dependencies

```bash
npm install
```

### 4. Start the Development Server

```bash
npm run dev
```

Open the local URL displayed in your terminal, usually `http://localhost:5173/`.

## 🔑 API Configuration

This project uses a weather API to fetch weather information.

1. Get an API key from your chosen weather API provider.
2. Configure the API key in the appropriate environment variable or project configuration.
3. Keep private API keys out of public repositories.
